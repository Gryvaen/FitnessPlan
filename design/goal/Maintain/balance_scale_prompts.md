## 以下为设计过程记录

用途：维持境界主页以天平为背景主角，替换 `goal_maintain_background.jpg` 占位图和代码绘制的天平。出图工具：ChatGPT。

## 风格基调：与 App 的水墨 UI 统一
参考 App 现有界面（`design/ink-ui/`、`design/display/`）：
- **底**：宣纸米白（≈ #F3F0E8），带极淡的纸纹
- **笔**：黑墨书法笔触，起笔重、收笔轻，干笔飞白，线条有粗细变化
- **强调色**：深青墨（≈ #1F5F5B），与"今日"页的进度圆环、水杯同色
- **点睛**：一枚朱红小印章（≈ #B5432F）
- **构图**：大面积留白，极简，写意而非写实
- **不要**：写实质感、金属反光、3D 渲染、修仙元素（太极、灵光、仙气）、繁复装饰

天平语义：左盘 = 亏空，用青墨；右盘 = 盈余，用赭石（暖褐），都要淡雅、低饱和。

天平要能在代码里倾斜、做动画，所以**部件单独出图**，背景单独出一张不带天平的。

## 出图顺序
1. 先出 **概念图**，把笔墨风格定下来
2. 满意后，在**同一个对话**里依次出：背景 → 底座 → 横梁 → 吊盘 → 砝码，每次都说"严格沿用上面概念图的笔墨风格"
3. 每张都检查：正面平视、背景干净、没有文字、笔触粗细和概念图一致

> 水墨的晕染边缘很难完美抠成透明。部件图可以要求**纯白背景**，接入 App 时我用"正片叠底"（multiply）把白底叠在宣纸背景上去掉，效果比抠图更自然。

## 进阶版：「日月同衡」（更有意境、更惊艳）

思路：左盘盛一弯青月（阴、清、亏空），右盘托一轮赭红的日（阳、暖、盈余），天平称的是阴阳。
接入 App 时，砝码改成月与日：哪边热量多，哪边的月或日就放大，数值直接变成画面。

### A. 在现有概念图上修改（发图后接着说）
```
在这张图的基础上提升艺术感，让它更惊艳、更有意境，保持宣纸、水墨、留白的整体风格：
1. 横梁改成一笔更利落的书法横画：中间略重，向两端逐渐收细，末端干笔飞白自然散开，不要上卷，不要像胡须；横梁要有起笔的顿挫和速度感。
2. 墨色拉开层次，要有焦墨、浓墨、淡墨、清墨的对比：支点和立柱上段用焦墨，立柱下段渐淡并有飞白；墨迹边缘要有宣纸上自然的渗化。
3. 去掉盘里的毛绒圆点。左盘里盛一弯青色的新月，用青墨（#1F5F5B）淡淡晕染；右盘托着一轮赭红色的太阳，用淡朱砂和赭石晕染，边缘柔和渗开。日与月是全画仅有的两处颜色。
4. 吊盘用更薄的淡墨一笔画出，碗底留一点水痕般的晕染。
5. 底座山石用更松的皴擦，墨色更淡，几乎融进纸里；石下加一道极淡的水痕或雾气，让天平像立在水边。
6. 周围加入极少的环境：远处若有若无的淡墨远山，或几点飞溅的细小墨点，增加呼吸感。
7. 保留右下角朱红「衡」字印章。
整体：克制、留白、高级，像一幅可以装裱的现代水墨小品。不要写实，不要 3D，不要仙侠元素，不要其他文字。
```

## 常见问题与补救
- **太写实、有 3D 感**：追加「这是平面的水墨画，不是渲染图，只用毛笔笔触和墨色晕染」
- **太满、太繁复**：追加「更多留白，减少笔画，极简写意」
- **颜色太艳**：追加「墨色淡雅，青墨和赭石都要低饱和，像宣纸上的水墨」
- **风格跑偏**：追加「严格参考第一张概念图的笔触粗细、墨色浓淡和留白比例」
- **出现透视**：追加「正面平视，像平面图标」
- **出现多余文字**：追加「画面中除指定印章外不得出现任何文字」
