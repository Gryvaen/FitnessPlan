## 已确认的关键细节

- 新用户默认清新绿；可选极光、暖阳、石墨。保存用户主题选择，兼容老主题设置。
- 首页上排：剩余热量、热量圆环、小水杯；水杯在最右侧，与圆环高度相近。
- 同一张卡下排：蛋白质、碳水、脂肪、饮水四列；不要另建饮水卡。
- 水杯精致轻薄，保留杯身加水、杯盖撤回；杯子与圆环不能因加入策略标签而挤压变形。
- 今日训练和今日饮食默认折叠，各有纯加号与独立展开箭头；沿用原添加流程，也保留原有溢出菜单功能。
- 底部仍为四个纯图标的悬浮胶囊导航，不加文字、不新增中间大按钮。
- 减脂策略改变所选日期的热量与宏量目标，不覆盖过去的计划或补录历史。
